PyWordle

Yet another Wordle port, this time in Python!

PyWordle is a project ran solely by xbennies. The goal is to have Wordle running in a website with web leaderboards and a word of the day, all in the great Python language.

Right now, the project is in a very early state, being very buggy and running via CLI. On top of that, I am a very busy person IRL so development will be very slow to progress.
